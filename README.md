This repository contains some of the files used in the thesis **Using Large Language Models to Improve the Quality of Phishing Emails**.


* Assessment results: Contains the csv files with the LLM output for the email assessment task.
* Rewriting results: Contains the csv files with the LLM output for the email rewriting task.
* Feedback framework: Contans all code for the overall feedback framework, including all prompts.


* Assessment dataset: 1200 mails that were used in the analysis (Note that emails 600-699 are LLM-generated and were omitted from analysis).
* Labelled Ground Truth: ATLAS.ti project with labelled ground truth.
* Labelling Ground Truth Codebook: Codebook that was used for creating the Labelled Ground Truth.
