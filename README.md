This repository contains some of the files used in the thesis **Using Large Language Models to Improve the Quality of Phishing Emails**.


* Assessment results: The csv files with the LLM output for the email assessment task.
* Rewriting results: The csv files with the LLM output for the email rewriting task.
* Feedback framework: Code for the overall feedback framework, including the prompts.


* Assessment dataset: 1200 mails that were used in the analysis (Note that emails 600-699 are LLM-generated and were omitted from analysis).
* Labelled Ground Truth: ATLAS.ti project with labelled ground truth that was used for the qualitative analysis of email assessment.
* Labelling Ground Truth Codebook: Codebook that was used for creating the Labelled Ground Truth.
